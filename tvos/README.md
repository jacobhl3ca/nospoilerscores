# HideScore for Apple TV

A native SwiftUI tvOS app. It is **not** a wrapper: tvOS has no `WKWebView`, so
none of the Capacitor machinery under `ios/` applies here. The app talks to
ESPN's public scoreboard directly and renders the board itself.

Ships inside the existing App Store record (`com.jacobhl.hidescore`, app id
`6766885311`) as a second platform, so it is a **universal purchase** — one
listing, and anyone who has HideScore on their phone finds it on their Apple TV.

Since 1.1 it also owns the Home screen's **Top Shelf**: highlight the app icon
and last night's closest games and tonight's slate are right there, scores still
hidden, one press from the game.

## Why it's built this way

The website is ~32,000 lines of TypeScript. Re-implementing that in Swift would
guarantee drift, so only two things live in Swift, and both are pinned:

| Concern | Where it lives | How it stays honest |
| --- | --- | --- |
| Which leagues exist, ESPN paths, season windows, rating calibration (incl. football's closeness curve) | `public/tv/catalog.json`, fetched from hidescore.com on every launch | `npm run tv:catalog:check` fails if it drifts from `src/lib/espn.ts` |
| The worth-watching rating algorithm | `HideScoreTV/Model/Rating.swift` | `npm run tv:parity` scores live games with **both** implementations and diffs them |

Everything else — labels, paths, calibration numbers, the ESPN host — is data
the app downloads. **Adding a league is a website push, not an App Store
review.**

The Top Shelf extension compiles the very same `Model/` sources as the app (an
Xcode synchronized-group exception set adds them to the second target — no
copies, no framework), so the shelf can never rate or filter a game differently
from the board.

## Layout

```
HideScoreTV/
  Model/      Catalog, ESPN parsing, the rating port, preferences, app state,
              SharedPreferences (the app-group mirror the Top Shelf reads)
  Views/      Tonight, Worth Watching, Leagues, Settings, card + detail
  Resources/  catalog.json — bundled fallback for a cold launch with no network
  Assets.xcassets/  layered tvOS icon + static top shelf, generated by tools/make-assets.py
HideScoreTopShelf/   the TVServices extension (com.jacobhl.hidescore.topshelf)
  ContentProvider   loadTopShelfContent(): sections → TVTopShelfSectionedContent
  ShelfBuilder      which games make the shelf, in what order (pure, testable)
  ShelfRenderer     draws each tile as a PNG with CoreGraphics + CoreText
tools/
  make-assets.py    regenerates every brand asset from public/monkey-see-no-evil.svg
  parity/           the TypeScript ↔ Swift rating parity harness
  smoke/            the real catalog, the real ESPN requests, the real board — no scores printed
  shelf/            renders tonight's Top Shelf tiles on macOS, no simulator needed
  screenshots.sh    builds, installs and captures the five App Store screenshots in demo mode
  ship.sh           archive → sign → upload, headless
  submit.py         App Store Connect: status, metadata, screenshots, attach, submit
```

## Commands

```bash
npm run tv:catalog          # regenerate public/tv/catalog.json + the bundled copy
npm run tv:catalog:check    # CI gate — non-zero when the catalog is stale
npm run tv:parity           # prove Rating.swift == calculateRating() on live data
tvos/tools/smoke/smoke.sh   # parse today's real scoreboards with the app's own code
tvos/tools/shelf/shelf.sh   # build + render the Top Shelf for right now → tools/shelf/out/
tvos/tools/screenshots.sh   # the five listing screenshots (demo mode, simulator)
/opt/homebrew/bin/python3 tvos/tools/make-assets.py   # rebuild icon + static top shelf

# build / run
xcodebuild -project tvos/HideScoreTV.xcodeproj -scheme HideScoreTV \
  -destination 'platform=tvOS Simulator,name=Apple TV 4K (3rd generation)' build
```

App Store screenshots are captured with demo mode, which anonymizes every team,
league and broadcaster so no trademark reaches the listing (HideScore was
rejected twice under 4.1(a) for exactly that):

```bash
xcrun simctl launch booted com.jacobhl.hidescore -HSDemoMode YES
```

## Top Shelf

`HideScoreTopShelf` is a `TVTopShelfContentProvider`. tvOS calls it when the
icon is focused on the Home screen, and the app pokes it
(`topShelfContentDidChange()`) whenever a load changes a game's state, status or
rating — so a game that just went final shows up without anyone opening the app.

- **Two sections.** *Worth watching*: finals from today and yesterday rated
  GOOD or better, best first. *On tonight*: today's unfinished games, live
  first, then by start time. Ten tiles each, only the leagues the user follows.
- **Tiles are drawn, not photographed.** `ShelfRenderer` paints each one
  (league, status or LIVE clock, both teams with logos, the rating badge, the
  channel) as a PNG into the app-group container, which is where the system
  reads Top Shelf images from. It uses CoreGraphics + CoreText only, so
  `tools/shelf` renders byte-identical tiles on macOS for review.
- **Spoiler-safe by the same rules as the board.** No score ever appears; a
  final says "Final" and never "Final/10"; records are hidden on finals; a
  live game shows its clock, which says how far along it is, not who leads.
- **Deep links.** Every tile opens `hidescore://game?league=<key>&id=<id>&day=<yyyymmdd>`,
  which `RootView.onOpenURL` resolves to the live copy of that game and presents
  the detail card. Selecting a tile is a display action — there is no video, so
  the review notes' "no playback of any kind" stays true.
- **The app group is the whole bridge.** `group.com.jacobhl.hidescore` carries
  the followed leagues and the ratings toggle (`SharedPreferences`, mirrored on
  every change) and the rendered tiles. Without the entitlement the extension
  silently sees the catalog defaults and an empty image store — see Shipping.

## Shipping

```bash
tvos/tools/ship.sh          # archive + upload at the current version/build
tvos/tools/ship.sh 1.2 3    # bump marketing version / build first
/opt/homebrew/bin/python3 tvos/tools/submit.py status
```

Things about a tvOS upload that are not guessable, all encoded in the scripts
so the next release doesn't rediscover them:

- **The App Store icon's idiom is `tv`, not `tv-marketing`.** The 1280x768 stack
  compiles without a single actool warning under `tv-marketing` and lands in
  `Assets.car` at the right size — and is then invisible to App Store validation,
  which rejects the upload with *Missing Image Asset ... App Store Icon*. One
  word in the brand assets' `Contents.json` is the whole difference.
- **The archive is built unsigned and the export signs it.** Automatic signing
  provisions an archive for *development*, and a development profile can't be
  issued to a team with no registered devices — which is this one, since nothing
  here is ever side-loaded. Forcing `CODE_SIGN_IDENTITY=Apple Distribution`
  instead trips "conflicting provisioning settings".
- **…but the archived bundles must be ad-hoc signed before the export.** The
  export re-signs with whatever entitlements it finds on the archive, and an
  unsigned archive has none: the 1.0 recipe exported 1.1 *successfully* with the
  App Groups entitlement missing from both the app and the extension. A plain
  `codesign -s - --entitlements` on each bundle is what the export reads them
  from: it validates them against the store profile and applies the real
  signature (that validation is how the missing portal App Group surfaced).
  Ad-hoc signing at archive time is refused outright ("requires a provisioning
  profile").
- **The App Group is registered in the developer portal, once, by hand.**
  `group.com.jacobhl.hidescore` must exist and be enabled on both App IDs.
  The App Store Connect API has no App Group resource, and `xcodebuild
  -allowProvisioningUpdates` cannot create one with an API key — it fails with
  `Authentication failed` and then *doesn't include the App Groups capability*.
  (Registering the `.topshelf` bundle id, by contrast, it did on its own.)
- **`exportArchive` needs Apple's rsync.** Homebrew's rsync 3.4.x fails it with a
  bare `Copy failed`; the real error is buried in the `.xcdistributionlogs`
  bundle. `ship.sh` runs the export with a system-only `PATH`.

## Proof, not assertion

Both pins are things you can run, and both were run before each version shipped:

```
$ npm run tv:parity          # 3 days, every league, live ESPN payloads (2026-09-05)
compared 121 games · 0 mismatched · 0 not parsed by Swift

$ tvos/tools/smoke/smoke.sh
total 41 games · 1 rated · 0 league fetch failures

$ tvos/tools/shelf/shelf.sh
catalog 32 leagues · 2 sections · 20 tiles · 38 logos · 0.7s
```

`smoke.sh` and `shelf.sh` deliberately print no scores. They are checking the
board, and the board never shows one.

What the harness has caught so far — the reason it exists:

- **1.0 rated every 1-0 soccer final 15 points too high.** The port took -10 for
  a one-goal match where the site takes -25. Parity on 2026-09-05 flagged all
  three 1-0 finals in the window and nothing else; 1.1 restores the site's
  numbers.
- **Football's closeness curve has to travel through the catalog.** On 9/4 the
  site started reading a football margin as *how many scores it takes to tie*
  (`src/lib/marginCloseness.ts`). That constant is referenced by name from
  `SPORT_RATING_CONFIG`, which broke both `tv:catalog:check` and the parity
  extractor with `FOOTBALL_CLOSENESS is not defined` until the generator learned
  to carry it (`rating.closenessCurve`, knots of `[margin, closeness]`) and
  `Rating.closeness` learned to walk it.
- **ESPN dates have no seconds** (`2026-09-05T23:30Z`), which `ISO8601DateFormatter`
  refuses, so every start time in 1.0 was nil — "Scheduled" instead of
  "7:10 PM", and the Top Shelf's tonight section sorted by nothing. `ESPN.date`
  now tries the no-seconds shape first.

## Scope

v1 covers the 32 leagues that parse out of ESPN's standard two-competitor
scoreboard. Deliberately excluded, each because it needs its own parser or a
worker route the app doesn't call: golf and tennis (leaderboards / draw
groupings), racing and combat sports (single-event tiles rather than games),
chess, poker and esports. `scripts/build-tv-catalog.mjs` lists them and throws if
a supported sport disappears from `ALL_LEAGUES`.
