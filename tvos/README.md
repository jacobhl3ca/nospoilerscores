# HideScore for Apple TV

A native SwiftUI tvOS app. It is **not** a wrapper: tvOS has no `WKWebView`, so
none of the Capacitor machinery under `ios/` applies here. The app talks to
ESPN's public scoreboard directly and renders the board itself.

Ships inside the existing App Store record (`com.jacobhl.hidescore`, app id
`6766885311`) as a second platform, so it is a **universal purchase** — one
listing, and anyone who has HideScore on their phone finds it on their Apple TV.

## Why it's built this way

The website is ~32,000 lines of TypeScript. Re-implementing that in Swift would
guarantee drift, so only two things live in Swift, and both are pinned:

| Concern | Where it lives | How it stays honest |
| --- | --- | --- |
| Which leagues exist, ESPN paths, season windows, rating calibration | `public/tv/catalog.json`, fetched from hidescore.com on every launch | `npm run tv:catalog:check` fails if it drifts from `src/lib/espn.ts` |
| The worth-watching rating algorithm | `HideScoreTV/Model/Rating.swift` | `npm run tv:parity` scores live games with **both** implementations and diffs them |

Everything else — labels, paths, calibration numbers, the ESPN host — is data
the app downloads. **Adding a league is a website push, not an App Store
review.**

## Layout

```
HideScoreTV/
  Model/      Catalog, ESPN parsing, the rating port, preferences, app state
  Views/      Tonight, Worth Watching, Leagues, Settings, card + detail
  Resources/  catalog.json — bundled fallback for a cold launch with no network
  Assets.xcassets/  layered tvOS icon + top shelf, generated by tools/make-assets.py
tools/
  make-assets.py    regenerates every brand asset from public/monkey-see-no-evil.svg
  parity/           the TypeScript ↔ Swift rating parity harness
```

## Commands

```bash
npm run tv:catalog          # regenerate public/tv/catalog.json + the bundled copy
npm run tv:catalog:check    # CI gate — non-zero when the catalog is stale
npm run tv:parity           # prove Rating.swift == calculateRating() on live data
/opt/homebrew/bin/python3 tvos/tools/make-assets.py   # rebuild icon + top shelf

# build / run
xcodebuild -project tvos/HideScoreTV.xcodeproj -scheme HideScoreTV \
  -destination 'platform=tvOS Simulator,name=Apple TV 4K (3rd generation)' build
```

App Store screenshots are captured with demo mode, which anonymizes every team,
league and broadcaster so no trademark reaches the listing (HideScore was
rejected twice under 4.1(a) for exactly that):

```bash
xcrun simctl launch booted com.jacobhl.hidescore -HSDemoMode YES
```

## Scope

v1 covers the 32 leagues that parse out of ESPN's standard two-competitor
scoreboard. Deliberately excluded, each because it needs its own parser or a
worker route the app doesn't call: golf and tennis (leaderboards / draw
groupings), racing and combat sports (single-event tiles rather than games),
chess, poker and esports. `scripts/build-tv-catalog.mjs` lists them and throws if
a supported sport disappears from `ALL_LEAGUES`.
